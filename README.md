# Everleaf

## Description

Everleaf is a sleek and intuitive notes app where you can create, edit, and delete notes. Each note requires a title and content, and you can choose a custom color (the default color of a note is white). The creation date is displayed for easy tracking. Built with a RESTful architecture, Everleaf uses a database for persistent storage and a server to handle CRUD operations, ensuring smooth and efficient note management.

## Technologies Used

* React.
* Node.js.
* Express.js.
* MongoDB.
* Axios.

## Installation and Usage

**1. Clone the repository**  
git clone https://github.com/AndreiCIlies/Everleaf.git  
cd pathToClonedRepository

**2. Install dependencies**  
npm install

**3. Set up environment variables**  
Update the MONGO_URI value in the .env file with your MongoDB connection string.

**4. Run the server**  
Navigate to the Backend directory and start the server: node server.js

**5. Run the application**  
Navigate to the Frontend directory and start the application: npm start

The app will be available at http://localhost:3000
